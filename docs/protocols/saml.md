## Outbound SAML IdP

XID acting as a SAML Identity Provider that issues SAML Response/Assertion to a downstream SaaS. The outbound SAML IdP baseline is implemented and passes fake SaaS SP L3. Public docs do not promise that Slack/GitHub Enterprise/Microsoft custom app/Atlassian/Salesforce/Zoom are production-supported. Auth0 outbound SSO marketplace and custom SAML/OIDC docs prove this is a distinct downstream product surface, and it MUST NOT be substituted by inbound SAML SP, generic OAuth/OIDC IdP, Social OAuth, or Clerk OAuth SSO comparison.
