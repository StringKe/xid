# @xid-kit/protocol

OAuth, OIDC, and PKCE protocol helpers shared by the XID SDK packages.

This package is built as a runtime dependency of the client SDKs that use its protocol helpers.
After an authorized npm release, applications will normally receive it through another
`@xid-kit/*` package.

Distribution status: release artifacts are verified locally, but no npm publish has been performed.
See https://github.com/StringKe/xid/blob/main/docs/sdks/distribution.md.
